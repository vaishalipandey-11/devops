| Dockerfile                                          | docker-compose.yml                                        |
| --------------------------------------------------- | --------------------------------------------------------- |
| Describes **how to build one image**                | Describes **how to run multiple containers together**     |
| Used to create an image                             | Used to create and manage containers                      |
| One application/service                             | Entire application stack                                  |
| Contains build instructions                         | Contains runtime configuration                            |
| Written once per service                            | Usually one file for the whole project                    |
| Uses instructions like `FROM`, `COPY`, `RUN`, `CMD` | Uses keys like `services`, `ports`, `volumes`, `networks` |
