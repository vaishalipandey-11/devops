# Containers
A container is a running instance of an image.

| Command                              | Meaning                                  |
| ------------------------------------ | ---------------------------------------- |
| `docker run IMAGE`                   | Create and start a new container.        |
| `docker run -d IMAGE`                | Run container in background.             |
| `docker run -it IMAGE bash`          | Start an interactive shell.              |
| `docker run --name NAME IMAGE`       | Assign a custom container name.          |
| `docker run -p HOST:CONTAINER IMAGE` | Map host port to container port.         |
| `docker ps`                          | List running containers.                 |
| `docker ps -a`                       | List all containers.                     |
| `docker images`                      | List available images.                   |
| `docker logs CONTAINER`              | View container logs.                     |
| `docker logs -f CONTAINER`           | Follow logs in real time.                |
| `docker exec -it CONTAINER bash`     | Open a shell inside a running container. |
| `docker inspect CONTAINER`           | Show detailed container information.     |
| `docker start CONTAINER`             | Start a stopped container.               |
| `docker stop CONTAINER`              | Gracefully stop a container.             |
| `docker restart CONTAINER`           | Restart a container.                     |
| `docker rm CONTAINER`                | Remove a stopped container.              |
| `docker rm -f CONTAINER`             | Force remove a running container.        |
| `docker container prune`             | Remove all stopped containers.           |
| `docker stats`                       | Monitor live CPU and memory usage.       |
| `docker cp HOST_FILE CONTAINER:PATH` | Copy file from host to container.        |
| `docker cp CONTAINER:PATH HOST_PATH` | Copy file from container to host.        |

| Option      | Meaning                                      |
| ----------- | -------------------------------------------- |
| `-d`        | Detached (background) mode.                  |
| `-it`       | Interactive terminal.                        |
| `--name`    | Assign a custom container name.              |
| `-p`        | Publish ports (`host:container`).            |
| `-e`        | Set environment variables.                   |
| `-v`        | Mount a volume or bind mount.                |
| `--rm`      | Remove the container after it exits.         |
| `--network` | Connect the container to a specific network. |
| `--restart` | Configure automatic restart policy.          |

Docker: Run an Application (Nginx Example)
| Step | Command                                     | Meaning                                                                                               |
| ---- | ------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| 1    | `docker pull nginx`                         | Download the Nginx image from Docker Hub.                                                             |
| 2    | `docker images`                             | Verify the image is downloaded.                                                                       |
| 3    | `docker run -d --name web -p 8080:80 nginx` | Create and run  in the background, mapping host port `8080` to container port `80`.                   |
| 4    | `docker ps`                                 | Verify the container is running.                                                                      |
| 5    | `http://<EC2_PUBLIC_IP>:8080`               | Access the application from your browser.                                                             |
| 6    | `curl localhost:8080`                       | Verify the application locally on the EC2 instance.                                                   |
| 7    | `docker logs web`                           | View the container logs.                                                                              |
| 8    | `docker logs -f web`                        | Follow logs in real time.                                                                             |
| 9    | `docker exec -it web bash`                  | Open a shell inside the running container.                                                            |
| 10   | `docker inspect web`                        | View detailed container configuration.                                                                |
| 11   | `docker stats`                              | Monitor CPU, memory, and network usage.                                                               |
| 12   | `docker stop web`                           | Stop the application.                                                                                 |
| 13   | `docker start web`                          | Start the stopped application.                                                                        |
| 14   | `docker restart web`                        | Restart the application.                                                                              |
| 15   | `docker rm -f web`                          | Remove the container.                                                                                 |

EC2 Requirement
| Setting        | Value                                               |
| -------------- | --------------------------------------------------- |
| Security Group | Allow **TCP 8080**                                  |
| Browser URL    | `http://<EC2_PUBLIC_IP>:8080` (**HTTP**, not HTTPS) |
