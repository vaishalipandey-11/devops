| Step | Command                         | Meaning                                                                      |
| ---- | ------------------------------- | ---------------------------------------------------------------------------- |
| 1    | `sudo apt update`               | Updates the local package index.                                             |
| 2    | `sudo apt upgrade -y`           | Upgrades all installed packages to the latest versions.                      |
| 3    | `sudo apt install -y docker.io` | Installs Docker Engine from the Ubuntu repository.                           |
| 4    | `sudo systemctl start docker`   | Starts the Docker service.                                                   |
| 5    | `sudo systemctl enable docker`  | Enables Docker to start automatically on boot.                               |
| 6    | `sudo systemctl status docker`  | Checks whether the Docker service is running.                                |
| 7    | `sudo usermod -aG docker $USER` | Adds the current user to the `docker` group to run Docker without `sudo`.    |
| 8    | `newgrp docker`                 | Applies the new group membership without logging out.                        |
| 9    | `docker --version`              | Displays the installed Docker version.                                       |
| 10   | `docker version`                | Shows Docker Client and Server (Engine) versions.                            |
| 11   | `docker info`                   | Displays detailed Docker system information.                                 |
| 12   | `docker run hello-world`        | Downloads (if needed) and runs a test container to verify Docker is working. |
| 13   | `docker ps`                     | Lists running containers.                                                    |
| 14   | `docker ps -a`                  | Lists all containers (running and stopped).                                  |
| 15   | `docker images`                 | Lists all Docker images stored locally.                                      |

docker.io → Docker package maintained by Ubuntu.
docker-ce → Docker Community Edition from Docker's official repository (newer, recommended for production).
If using docker-ce, first add Docker's official repository and GPG key before installing docker-ce, docker-ce-cli, and containerd.io.

 # Virtualization

Virtualization is the process of creating multiple virtual computers (VMs) on a single physical machine using a Hypervisor.

+--------------------------------------+
|        Physical Server (Hardware)    |
| CPU | RAM | Disk | Network           |
+-------------------+------------------+
                    |
               Hypervisor
        (VMware, VirtualBox, KVM)
                    |
      +-------------+-------------+
      |             |             |
    VM-1          VM-2         VM-3
+---------+    +---------+   +---------+
| Ubuntu  |    | CentOS  |   | Windows |
| Apps    |    | Apps    |   | Apps    |
+---------+    +---------+   +---------+

Type-1 (Bare Metal): Runs directly on hardware.
Examples: VMware ESXi, Hyper-V, Xen
Type-2 (Hosted): Runs on top of an existing OS.
Examples: VirtualBox, VMware Workstation

 | Component                 | Meaning                                                    |
| ------------------------- | ---------------------------------------------------------- |
| Docker Client             | CLI (`docker`) used by the user.                           |
| Docker Daemon (`dockerd`) | Main service that manages Docker resources.                |
| Docker Engine             | Client + Daemon + REST API.                                |
| Images                    | Read-only templates to create containers.                  |
| Containers                | Running instances of images.                               |
| Volumes                   | Persistent storage.                                        |
| Networks                  | Communication between containers.                          |
| `containerd`              | Manages container lifecycle.                               |
| `runc`                    | Creates and starts containers using Linux kernel features. |
| Linux Kernel              | Provides namespaces, cgroups, filesystem, networking.      |
