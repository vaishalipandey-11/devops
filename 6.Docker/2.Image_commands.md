# IMAGES

A Docker Image is a read-only template used to create containers.

docker images          # List images
docker pull nginx      # Download image
docker image inspect nginx
docker image rm nginx  # Remove image
docker rmi nginx       # Same as above

# Image Layers
          Docker Image
        +-----------------+
        | App Layer       |
        +-----------------+
        | Dependencies    |
        +-----------------+
        | Ubuntu Layer    |
        +-----------------+
        | Base Layer      |
        +-----------------+
 Image = Stack of read-only layers.
Each Dockerfile instruction (RUN, COPY, ADD) creates a new layer.
Layers are cached and shared between images.
Only the top container layer is writable.

docker history nginx // shows layer fo that image
docker image ls
